How it decides

1 · It reads what already happened

Calendar, Stripe, Health, mail. Nothing in the signal registry means no task — the coach is not allowed to invent work it cannot measure.

2 · It runs money → machine → you

Can this be bought? Say the price. Can it be automated? Say how. Only what is left reaches your hands. The cheapest task is the one you never do.

3 · Nine gates, in code

The model writes the sentence. Code decides whether the task ships: budget, repeats, safety, and whether it lands on a block you marked untouchable.

4 · Three touches, one task

07:00 assigns. 13:00 asks where you are stuck. 21:00 closes the day. No new work after 07:00 — three touches with three new tasks is harassment, and that is when people mute an app.
